:: basic git

git add [name] ... them tep vao index ...

git commit -m "description" ... tao commit -> repo ...

git status  ... su khac biet giua 3 cay ...

git diff  ... so sanh voi commit cuoi cung ...

git log ... lich su commit ...


:: remote central

git init --bare ... tao mot central ...
git clone [link] [name]   ... sao chep va lien ket repo-name ...
git fetch   ... lay cac thong tin ve commit moi tu  central ...
git pull   ... lay du lieu tu central ve local repo ...
git push   ... day cac commit tu repo len central ...


:: checkout commit

git checkout [commit_hash] ... quay ve commit minh muon ...


:: Branch
git branch -M main ... doi ten nhanh master thanh nhanh main ...
git branch [name]  ... tao nhanh ...
git checkout [name]   ... chuyen doi cac nhanh ...
git branch -l || git branch   ... xem danh sach cac nhanh hien tai dang lam viec ...
git push --set-upstream origin [name of branch exists]  ... khi push nhanh moi tao len repo phai lam lenh nay ...
git branch -d [Branch]  ... xoa nhanh local ...
git push origin -d [Branch] ... xoa nhanh tren centralRepo ...

git branch -l ... kiem tra nhanh local ...
git branch -a ... kiem tra nhanh centralRepo ...

:: git rebase

<< sử dụng khi đang làm trên nhánh khác mà nhánh main bị thay đổi khi mình 
  muốn cập nhật nhánh main mà mình không muốn merge thì nên dùng rebase>>

--- đầu tiên là mình đang ở nhánh main muốn rebase main thì phải 
  chuyển sang nhánh đang làm việc sau đó gõ lệnh ---

git rebase [main]  ... tái cấu trúc ...

--- có thể bị conflict ở đây ---
--- khi sử lí conflict xong add vào ---

git add [file.txt]
git add . 

--- tiếp theo tiếp tục rebase bằng lệnh ---

git rebase --continue

<<  Nếu bạn không muốn giải quyết xung đột mà muốn bỏ qua commit đó, bạn có thể chạy lệnh >>
git rebase --skip   ... skip bỏ qua xung đột khi rebase mà gặt xung dột ...

git rebase --abort  ... Lệnh này sẽ hủy bỏ toàn bộ quá trình rebase và đưa branch của bạn trở về trạng thái trước khi rebase ...


:: git reset

git reset --soft [id commit] ... du lai tat ca ...
git reset [id commit] ... du file xoa stage ...
git reset --hard [id commit] ... xoa het tat ca thay doi cua file va stage ...

:: git revert

git revert HEAD ... quay ve commit gan nhat ...
git revert --no-edit HEAD ... quay ve lan commit gan nhat ma khong co edit ...

git revert [id commit] ... quay ve lan commit da duoc chi dinh ...
git revert --no-edit  ... quay ve lan commit da duoc chi dinh ma khong co edit ...


:: git fork

git remote -v ... xem thong tin fork ...
git remote add [new name] [link]  ... tao repo theo doi cac cap nhat cua repo chinh ...
git fetch [new name] ... keo repo chinh ve [new name] ...
git merge [new name] << lưu ý đang ở nhánh main>> ... merge [new name] về main ...

:: git remote

git remote -v ... kiểm tra git có liên kết với một central repo nào không ...
git remote remove [remote_name] .. xoá liên kiết giữa git và central repo ...

:: git remove files or folders were commit befor that
git rm -r --cached .vscode ... xóa .vscode khỏi repo ...


git symbolic-ref HEAD ... kiểm tra HEAD đang trỏ tới đâu ...

git reflog ... Nếu bạn sử dụng git reset --hard và HEAD bị mất, 
bạn có thể tìm lại HEAD hoặc khôi phục lại commit trước đó bằng cách sử dụng lệnh git reflog ...

git rm --cached appsettings.json // xoá theo dõi file này khỏi git
git rm --cached bin/ // xoá theo dõi folder này khỏi git
echo "appsettings.json" >> .gitignore // thêm dòng này vao file .gitignore

git push origin main --force // kéo tất cả code trong repo local push lên remote

git commit --amend --no-edit // commit nhưng không thêm commit

important !!!!
git reset --soft HEAD~1 // (HEAD~1 quay lại commit trước đó) nhưng (--soft không làm mất code)
git restore --staged appsettings.json // Gỡ appsettings.json ra khỏi staging (index) nhưng không xóa nội dung file

git branch // xem đang ở detached hay main
